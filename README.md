# Murkio identity for Go

`github.com/ViitoJooj/auth/libs/external/go` (package `murkio`): tells who is behind
each request and writes the login components into the pages you render. Standard
library only, Go 1.22+. The only setting is your publishable key.

```sh
MURKIO_PUBLISHABLE_KEY=pk_...    # MURKIO_API_URL is optional
```

```go
m, err := murkio.FromEnv()
if err != nil {
	log.Fatal(err)
}

// Protect routes; the session (and the profile with WithUser) goes in the context.
http.Handle("/dashboard", m.Middleware(murkio.Required(), murkio.SignInURL("/login"), murkio.WithUser())(dashboard))
http.Handle("/admin", m.Middleware(murkio.Roles("admin"))(admin))

func dashboard(w http.ResponseWriter, r *http.Request) {
	session := murkio.SessionFrom(r.Context()) // UserID, SessionID, Roles
	user := murkio.UserFrom(r.Context())       // Email, EmailVerified, MFAEnabled
	fmt.Fprintf(w, "Hello %s", *user.Email)
}
```

Pages with `html/template` (Hugo and other static sites use the script tag from
`@murkio/html` directly):

```go
page := template.Must(template.New("login").Funcs(m.TemplateFuncs(murkio.HeadOptions{AfterLogin: "/dashboard"})).Parse(`
<head>{{ murkioHead }}{{ .Bootstrap }}</head>
<body>
  {{ murkioCanvas }}
  <!-- or your own layout: -->
  {{ murkioEmailInput "input" }} {{ murkioPasswordInput "input" }} {{ murkioKeepLogged "Keep me signed in" }}
  {{ murkioLoginButton "Sign in" "btn" }} {{ murkioRegisterButton "Create account" "btn" }} {{ murkioError "" }}
</body>`))

bootstrap, _ := m.BootstrapScript(r.Context()) // inlines the canvas so it draws at once
page.Execute(w, map[string]any{"Bootstrap": bootstrap})
```

Gin, Echo or any other router: call `m.Authenticate(c.Request, murkio.WithUser())`
and read `result.Session`, or wrap the handler with `m.Middleware(...)`.

## How it works

- `GET /v1/client` (with the publishable key) gives the application, the token issuer
  and the JWKS. Access tokens are verified locally (Ed25519, `iss`, `aud`, `exp`); the
  keys are cached and fetched again only for an unknown `kid`. `CheckRevocation()` asks
  the API too (cached 30 s), so a logout or ban takes effect before the token expires.
- The token comes from `Authorization: Bearer` or from the session cookie the browser
  SDK writes (`__Host-murkio_session_<hash>`). The cookie only counts for GET, HEAD and
  OPTIONS or same-origin requests (CSRF); the unprefixed name only on localhost.
- A page request whose 15-minute session cookie expired, while the browser still holds
  a session, gets a short handshake page (CSP with a nonce, `no-store`) that refreshes
  the tokens and reloads; a 30-second guard cookie stops loops. `NoHandshake()` turns it off.
- `Head()` loads the `@murkio/html` bundle of this release pinned by its SRI hash
  (`cdn.go`, generated by `libs/scripts/sync-go-cdn.mjs`). Self-host it with
  `MURKIO_SCRIPT_URL` and `MURKIO_SCRIPT_INTEGRITY`.
- The backend never signs anyone in or refreshes tokens: the browser does, because the
  API rate-limits per user IP.
